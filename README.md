# ZthDeathProtect

一个简单的 Minecraft Spigot 插件，提供了两种死亡保护机制。

## 功能

本插件提供了两种独立的死亡保护功能：

1.  **基于附近玩家的保护**: 当一个玩家死亡时，如果其周围64x64范围内有8个或更多的玩家，该玩家的物品将会被保留（但经验值仍然会掉落）。这可以防止在大型活动或团战中因混乱而丢失物品。
2.  **基于权限的保护**: 拥有特定权限的玩家在死亡时可以保留所有物品和经验值。

## 权限

-   `zth.deathprotect.fullkeep`
    -   描述: 允许玩家在死亡时保留所有物品和经验值。
    -   默认: 仅授予服务器操作员 (OP)。

## 构建

本项目使用 Maven 构建。

```bash
mvn clean package
```

构建成功后，插件的 jar 文件将位于 `target` 目录下。
